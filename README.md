# Better Nether Portal

Minecraft 1.12.2 Forge mod. Replaces vanilla nether portals with a core-activated, auto-linking portal system.

## Development
- Requires Forge 1.12.2 (14.23.5.2860); builds with [Unimined](https://github.com/unimined/Unimined) and Java 8 (toolchain is auto-provisioned).
- `./gradlew runClient` / `./gradlew runServer` / `./gradlew build`
